# 软著源码范围与排除规则

## 1. 登记软件标识

1. 软件全称：新材料数据分析---拓扑感知多核集成聚类分析系统
2. 软件简称：新材料数据分析系统
3. 版本号：V1.0

## 2. 源码主体

1. 后端运行时代码
   - `backend/main.py`
   - `backend/app/`

2. 前端运行时代码
   - `front/src/` 下的 TypeScript、TSX 和样式代码
   - 排除测试文件、图片和构建环境声明

3. 任务执行边界
   - 保留 `backend/app/task_worker.py`，因为它承担平台参数转换、算法调用编排和结果产物标准化。
   - 不把 `ec_python_converted/` 算法转换实现认定为本次原创平台源码。

## 3. 主体排除项

1. `ec_python_converted/`：权属未单独确认的算法转换实现及测试夹具。
2. `backend/alembic/`、`backend/sql/`：数据库迁移和结构快照，放入内部备查材料。
3. `backend/tests/`、前端 `*.test.*`：测试代码不进入源码 PDF 主体。
4. 依赖锁文件、部署脚本、日志、缓存、构建产物、数据库文件和本地环境配置。
5. 图片、压缩包、MAT/NPZ 数据及其他二进制文件。

## 4. 生成规则

1. `source-manifest.json` 是可复现的范围配置。
2. 完整源码 PDF 按清单顺序收录全部平台运行时代码。
3. 提交摘录 PDF 与 DOCX 固定为 60 页，由完整文件组成前 30 页和后 30 页，不截断文件内容；DOCX 保持代码文本可编辑。
4. 每页包含软件全称、版本号、文件路径和页码，代码保留行号；PDF 使用语法配色，DOCX 使用等宽代码排版。
5. 生成过程同时输出源码文件清单、排除项清单、校验报告和可追溯 ZIP 包。若 PDF 正在被打开，可使用 `--submission-docx-only` 单独生成 Word 摘录。
