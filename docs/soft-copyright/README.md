# 软著登记与演示材料说明

本目录用于整理“新材料数据分析---拓扑感知多核集成聚类分析系统”的软著登记、答辩演示和项目归档材料。文档内容以当前代码仓库为准，避免登记材料、演示截图和实际系统能力不一致。

## 1. 软件基础信息

1. 软件名称
   - 新材料数据分析---拓扑感知多核集成聚类分析系统
   - 简称：新材料数据分析系统
   - 版本：V1.0

2. 适用场景
   - 面向新材料数据分析、集成聚类实验复现、聚类结果评估和报告导出。
   - 系统以桌面端 Web 工作台为主，不面向移动端适配。

3. 核心算法
   - OMELET
   - OMELET-SV
   - CA 协关联矩阵分析
   - 多核相似性学习

## 2. 功能清单

1. 用户与会话管理
   - 用户注册、登录、令牌刷新、退出登录。
   - 未登录或登录过期时，工作台入口跳转到登录页面。

2. 数据管理
   - 数据集上传、追加数据、重命名、删除、批量删除和导出。
   - 数据质量复核、标签分布、基础聚类统计和版本记录查看。

3. 任务中心
   - 创建 OMELET / OMELET-SV 分析任务。
   - 支持排队、启动、取消、重试、克隆、批量操作和模板保存。
   - 显示任务进度、当前轮次、当前迭代、运行耗时和失败原因。

4. 结果分析
   - 展示 CA 矩阵、核函数配置、多核相似性学习、性能评估、可视化结果和综合分析。
   - 支持任务结果刷新、代表轮次查看、指标导出和图表复核。

5. 报告与导出
   - 支持结果文件、指标表、参数快照、标签、矩阵产物和分析报告导出。
   - 保留最近导出记录，便于演示和归档。

6. 日志与审计
   - 记录任务创建、排队、执行、完成、失败、导出等操作日志。
   - 支持日志筛选、搜索、下载和上下文查看。

## 3. 源码模块说明

1. 前端模块
   - `front/src/LandingPage.tsx`：登录前首页和产品能力说明。
   - `front/src/AuthPages.tsx`：登录、注册和认证反馈。
   - `front/src/DatasetManagementPage.tsx`：数据集列表、上传、追加、详情和批量操作。
   - `front/src/workbench/tasks/`：任务中心、任务筛选、详情抽屉、创建抽屉和任务操作。
   - `front/src/workbench/results/`：结果总览、结果详情、日志页、图表面板和导出报告。
   - `front/src/components/`：通用表单组件。

2. 后端模块
   - `backend/main.py`：FastAPI 应用入口、路由挂载和启动生命周期。
   - `backend/app/auth.py`：用户认证和令牌接口。
   - `backend/app/datasets.py`：数据集上传、追加、质量检查、版本和导出。
   - `backend/app/tasks.py`：任务创建、调度状态、结果、导出和日志接口。
   - `backend/app/task_executor.py`：后台任务调度和算法子进程管理。
   - `backend/app/task_worker.py`：单个算法任务执行和结果产物生成。
   - `backend/app/models.py`：数据库模型。

3. 算法模块
   - `ec_python_converted/`：算法转换实现和开发测试夹具，暂不纳入本次原创平台源码 PDF。

## 4. 演示路径

1. 启动后端和前端。
2. 打开首页，进入登录或注册页面。
3. 登录后进入分析工作台。
4. 在数据管理页面上传或追加数据集。
5. 在数据质量检查页面复核样本、标签、基础聚类矩阵。
6. 在任务中心创建并启动 OMELET-SV 任务。
7. 查看任务进度、当前轮次、迭代状态和运行日志。
8. 进入结果分析页面，依次展示 CA 矩阵、核函数、多核学习、性能评估和可视化结果。
9. 在分析报告页面检查报告章节。
10. 在结果导出页面生成交付档案。
